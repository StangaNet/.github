# Participating in the StangaNet Community

Since StangaNet operates on a **read-only** model for code (meaning Pull Requests are not accepted), community engagement happens through discussion and observation. We value your curiosity, questions, and feedback!

## How to Engage

### 💬 GitHub Discussions
The primary way to interact with the maintainer and the community is through **GitHub Discussions** in the relevant repository.
* **Ideas & Feedback**: Have a suggestion for a new feature or an improvement to an existing library? Start a discussion!
* **General Questions**: Not sure how a specific library works? Ask the community or the maintainer in the "General" category.
* **Show & Tell**: Using a StangaNet library in a cool way? Share your experience!

### 🐛 Reporting Issues
If you find a bug, a typo in the documentation, or a way to improve the code, please open an **Issue**.
* **Bugs**: Use the `Bug Report` template. Provide as much context as possible (environment, reproduction steps, etc.).
* **Documentation**: Use the `Documentation` template to help us keep our guides clear and accurate.
* **Refactoring**: If you see code that could be cleaner or more efficient, use the `Refactor` template to propose an improvement.

## What to Expect

* **Maintainer-Led**: While we love community input, all code changes, architectural decisions, and release schedules are managed solely by the StangaNet maintainer.
* **Response Time**: We do our best to respond to issues and discussions, but please understand that this is a personal project. We do not offer formal Service Level Agreements (SLAs).
* **Respectful Conduct**: All interactions must adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

## Summary of Interaction Models

| Type of Input | Recommended Channel | Outcome |
| :--- | :--- | :--- |
| **Bug Report** | Issue | Maintainer reviews and fixes if appropriate. |
| **Feature Suggestion** | Discussion | Discussed by community; may be added to roadmap. |
| **Documentation Fix** | Issue | Maintainer updates the docs. |
| **General Question** | Discussion | Answered by community or maintainer. |
| **Code Contribution** | *N/A* | **Not currently accepted via Pull Requests.** |
