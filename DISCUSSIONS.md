# Discussions and Issues

StangaNet repositories are **read-only for code** (external pull requests are not accepted). Community interaction happens through Issues and Discussions.

## Discussions

**Discussions are enabled only on this `.github` repository.**

Use Discussions here for:

- Feature ideas and design feedback
- How-to questions
- Show-and-tell / usage examples

Do not expect Discussions on individual `StangaNetLib.*` repositories.

## Issues

Use Issues on the relevant repository for:

- Bugs (Bug Report template)
- Documentation gaps (Documentation template)
- Refactor / technical-debt proposals (Refactor template) — proposals only; no external PR

## What to expect

- The maintainer decides architecture, roadmap, and releases
- Responses are best-effort; there is no SLA
- All interaction must follow the [Code of Conduct](./CODE_OF_CONDUCT.md)
- Wiki is disabled everywhere
- Branch protection rulesets are active on all library repositories

| Input | Channel | Outcome |
| --- | --- | --- |
| Bug | Issue (on the library repo) | Reviewed; fixed if appropriate |
| Feature idea | Discussion (on `.github`) | May inform the roadmap |
| Docs fix suggestion | Issue | Maintainer may update docs |
| Question | Discussion (on `.github`) | Answered when possible |
| Code contribution | — | Not accepted via pull request |
