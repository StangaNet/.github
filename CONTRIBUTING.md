# Contributing to StangaNet

Thank you for your interest in StangaNet projects.

## Read-only repositories

StangaNet repositories are **personal projects** published for reference and learning.
They are **not open for external contributions**. Pull requests from outside the organization will not be reviewed or merged.

## What you can do

- Open **bug reports** with the Bug Report issue template on the relevant repository
- Open **feature requests** with the Feature Request template (ideas only — no PR expected)
- Start a **Discussion** if Discussions are enabled on that repository
- **Fork** under the terms of the [LICENSE](./LICENSE)

## What you cannot do

External code contributions (pull requests) are **not accepted**.

Under the Apache License 2.0 you **may** use the code commercially, modify it, redistribute it, and create derivative works. You **must** retain copyright notices and include a copy of the Apache License 2.0.

See [LICENSE](./LICENSE) for the full terms.

## Bug reports

Include:

- A clear description of the problem
- Steps to reproduce
- Environment (OS, runtime / package version)
- Expected vs actual behavior

## Security issues

Do **not** open public issues for security vulnerabilities.
Follow [SECURITY.md](./SECURITY.md).

## Code of conduct

All interactions in StangaNet spaces are governed by the [Code of Conduct](./CODE_OF_CONDUCT.md).
