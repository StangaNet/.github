# Contributing to StangaNet

Thank you for your interest in StangaNet projects.

## Read-only repositories

StangaNet repositories are **personal projects** published for reference and learning.
They are **not open for external contributions**.

- **Pull requests are not accepted** from anyone outside the organization (and external PRs will be closed without review).
- **Wiki is disabled** on all repositories.
- **Discussions are enabled only** on this `.github` repository. Use Issues on individual repositories for bugs and feature ideas.

Technical enforcement is in place via branch rulesets on all `StangaNetLib.*` repositories: changes to `main` require a pull request with at least one approving review, stale reviews are dismissed, force pushes and branch deletions are blocked.

## What you can do

- Open **bug reports** with the Bug Report issue template on the relevant repository
- Open **feature requests** with the Feature Request template (ideas only — no PR expected)
- Start a **Discussion** on the [`.github` repository](https://github.com/StangaNet/.github/discussions) (the only place Discussions are enabled)
- **Fork** under the terms of the [LICENSE](./LICENSE)

## What you cannot do

External code contributions (pull requests) are **not accepted**.
Wiki edits are not possible.

See [LICENSE](./LICENSE) for the full terms.

## Bug reports

Include:

- A clear description of the problem
- Steps to reproduce
- Environment (OS, runtime / package version)
- Expected vs actual behavior

## Security issues

Do **not** open public issues for security vulnerabilities.
Follow [SECURITY.md](./SECURITY.md).

## Code of conduct

All interactions in StangaNet spaces are governed by the [Code of Conduct](./CODE_OF_CONDUCT.md).
