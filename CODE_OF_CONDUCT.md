# Code of Conduct

## Standard

Interactions in StangaNet spaces (Issues, Discussions, comments) must be respectful and constructive.

Expected:

- Welcoming, inclusive language
- Respect for differing viewpoints
- Graceful acceptance of feedback
- Focus on what helps the project

Unacceptable:

- Insults, personal attacks, or derogatory language
- Spam or off-topic content
- Sharing others' private information without consent
- Conduct that would be inappropriate in a professional setting

## Enforcement

The maintainer may remove comments, close issues, and block users who violate this standard, without prior warning.

## Scope

Applies to all StangaNet-managed spaces on GitHub.

## Contact

Report violations privately via GitHub (maintainer contact or Private Vulnerability Reporting where appropriate).
